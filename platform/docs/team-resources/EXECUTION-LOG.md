# سجل تنفيذ وحدة الفريق والموارد (حزمة سند S01–S25)

**المصدر:** `SANAD_IMPLEMENTATION_KIT` (الإصدار 1.0 — 2026-09-05): الموجّه الرئيسي (20 قسماً، 45 حالة قبول) + 25 شاشة مرجعية. **قاعدة الحزمة:** قواعد العمل المكتوبة تعلو بيانات الصور؛ الصور مرجع الهوية والترتيب والتدرج. **قاعدة المستودع:** الكود + ADRs يعلوان أي مواصفة عند التعارض (`docs/README.md`).

هذا الملف هو السجل الواحد المطلوب في §3 من الموجّه: الوضع المثبت، قرارات التصميم والبيانات، خريطة الشاشات، تقدم المراحل، الفحوص والقيود. يُحدَّث مع كل مرحلة ولا يُستنسخ في تقارير متفرقة.

## 2. قرارات التصميم والبيانات (المرحلة B)

**مبدأ:** توسيع البنية القائمة (Node/Express/SSR/SQLite+PG) — لا إطار جديد، لا ORM، لا جداول مكررة. المفاهيم الجديدة تُربط بالموجود، والتحويل موثَّق هنا.

| مفهوم الموجّه | التمثيل في سند | ملاحظة |
|---|---|---|
| المورد | `employee` + أعمدة جديدة: `resource_type` (internal/external/partner)، `vendor_name` (الجهة المتعاقدة)، `engagement_ref` | القديم `employment_type` يبقى للعرض؛ التحويل: أساسي/موسمي ⇒ internal، متعاقد ⇒ external. |
| حساب الدخول | `app_user` كما هو | تعطيل الحساب لا يمسّ `employee` (T17). |
| فترة الارتباط | `employee.hire_date`/`end_date` + `resource_type` + `vendor_name` | لا جدول ارتباطات متعددة (شخص = ارتباط واحد ساري) — قيد معلن. |
| الطاقة بإصدارات مؤرخة | جدول جديد `capacity_version` (employee_id, effective_from, capacity_pct, note, created_by) | `employee.capacity_pct` يبقى **القيمة السارية** (يستهلكه 2146 اختباراً)؛ الإصدار الجديد يكتبه ويحفظ التاريخ. |
| القدرة/الخبرة/الهدف | جدول `resource_capability` (kind: skill/experience/goal، level، evidence، reviewed_at، reviewer) | التقييم الذاتي vs المراجَع = `reviewed_by` فارغ/ممتلئ. |
| وجهة العمل | القائم: مشروع، أو بند داخلي (bd/product/pmo)، أو فرصة (عضوية) | «منتج» = البند `product`؛ لا كيان منتج مستقل (قرار مالك — decision-log ق١). |
| المشاركة | `membership` + `allocation` القائمان | مشاركة الفرصة بلا نسبة لا تحجز طاقة (T05 مُحقَّق). |
| التسكين مؤكد/مبدئي + تصنيف تجاري | أعمدة جديدة على `allocation`: `status` (confirmed/tentative، الافتراضي confirmed للقائم)، `billable` (0/1، يُشتق افتراضياً: مشروع لعميل = 1، بند داخلي = 0) | المبدئي لا يُخصم من المتاح المؤكد (T02). |
| طلب التسكين | جدول `allocation_request` (المصدر، الهدف، الأشهر والنسب، النوع، الحالة، الإصدار المتوقع، بصمة، مفتاح عدم التكرار، المراجع، القرار وسببه) | يمرّ بمحرّك الاعتماد الموجَّه القائم (`raiseDirectApproval` + مُسوٍّ جديد)؛ الاعتماد يعيد فحص الطاقة داخل المعاملة (T20). |
| الاحتياج | جدول `resource_need` + `resource_need_candidate` (اختيار ⇒ طلب تسكين) | تسجيل الاحتياج لا يحجز. |
| التوزيع المالي/الإقفال/التصحيح | `cost_period` (النطاق=القطاع، الشهر، الحالة، الإصدار) + `cost_line` القائم؟ **لا** — جدول جديد `cost_share` (المورد، الشهر، جهة التحميل project/sector، الكود، النسبة بنقاط أساس، الأساس، الإصدار) + `cost_correction` | النسب بنقاط أساس (10000 = 100%) لا عائم. الإقفال يجمّد الإصدار؛ التصحيح ينشئ إصداراً جديداً. |
| المتابعة | جدول `analysis_case` (المورد، الفترة، الإشارة، الأدلة، الحالة) + مهمة عبر `quickAddTask` القائم | المتابعة مهمة حقيقية في «مهامي». |
| سجل الأثر | `audit_log` القائم | كل كتابة تمرّ بـ`audit()`. |

## 5. القيود المعلنة (لا تُخفى ولا تُخترع لها بيانات)

1. **حبيبة الشهر** في التسكين (C2): لا فترات داخل الشهر؛ التجاوز يُقاس شهرياً؛ بداية/نهاية الارتباط داخل الشهر تُتناسب بالأيام.
2. **لا تقويم عطل ولا إجازات**: المتاح «وفق الطاقة التعاقدية المسجلة».
3. **لا مشاركين متعددين على المهمة** (C7)؛ عبء المهام = «حِمل المهام» (D21) المشتق من النسب المكتوبة، وما بلا نسبة يُعرض «بلا نسبة مقدَّرة»؛ العبء بلا أي نسبة = **غير مقاس**.
4. **التغطية المالية للفرد غير متاحة** (C8).
5. **لا تكامل مالي خارجي**: حالة الترحيل «لم يتم» دائماً في هذه النسخة، والمخرج ملف CSV معتمد بالإصدار (T36).
6. **بيانات الصور تجريبية**: لا يُنشأ أحمد/نورة/خالد في الإنتاج؛ fixtures الاختبار معزولة.
7. **ارتباط واحد ساري لكل مورد** (`hire_date`/`end_date`) — لا سجل ارتباطات متعددة؛ تمديد العقد تعديلٌ مؤرخ في الأثر.
8. **الكود المالي للمشروع** يُقرأ من سجل المشروع (`project.financial_code`) لا من شاشة الإقفال؛ غيابه استثناءٌ يمنع الإرسال حتى يُسجَّل في صفحة المشروع.
9. **حسابات العرض (demo.*)** مستبعدة من سجل الموارد والإقفال لغير مدير النظام — موظفوها ليسوا موارد حقيقية.
10. **الربط الخارجي للمساعد (MCP/OAuth)** غير متحقق: السطح داخل التطبيق فقط حتى تتوافر إعدادات العميل والمصادقة (انظر `AI-TOOLS.md`).
