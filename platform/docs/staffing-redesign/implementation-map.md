# خريطة تنفيذ مساحة عمل التسكين (v5.26)

المصدر: حزمة المالك (Staffing Workspace — المصفوفة قلب المنتج) وصور الهدف كعقد بصري/تفاعلي؛
والحقيقة التشغيلية (الكود + الخدمات + القاعدة) تعلو أي صورة. كل مرساة متحقَّق منها بالقراءة.

## ١) النموذج القائم (Runtime Truth — يكفي بلا ترحيلة)

- `allocation` (ترحيلة 001:720): الصف = موظف × (مشروع XOR بند داخلي) × سنة؛ النِّسب في
  `monthly_json {1..12: 0–1.5}`؛ حذف ناعم؛ **لا `updated_at`** (مثبَّت باختبار
  `utilization-may2026:183`)؛ التفرّد تطبيقي: (موظف,مشروع,سنة) `projects.js:427` و
  (موظف,بند,سنة) `:374`. نافذة السنة ±(1,3) عبر `resolveAllocationYear` (`:337`).
- أهداف التسكين الحقيقية: **مشروع** + **البنود الثلاثة** `WORK_BUCKETS=['bd','product','pmo']`
  «تطوير أعمال/تطوير منتجات/إدارة مشاريع» (`projects.js:361`، `glossary.js:443` — قرار مالك
  مثبَّت باختبار «لا أكثر ولا مفتاحاً مخترعاً»).
- `employee.hire_date` (006) و`end_date` (008) و`capacity_pct` (017) موجودة؛ **لا مسار إشغال
  يقرأ التواريخ** — أساس حساب الفجوات. **لا تأريخ هيكلي** (رفضٌ موثَّق في رأس ترحيلة 007).
- الإشغال: `staffingRoster` (`org.js:605`) — months[12] لكل موظف (كل الأنواع) + حمل الفرص
  الناعم على الشهر الحالي فقط (PENDING مستثناة) + summary بعتبات 110/40. **70/110 تحذير لا
  منع** — لا فحص سعة على أي مسار كتابة (القصّ 150 لكل خلية).

## ٣) دلتا الخلفية (إضافية بحتة — لا ترحيلة)

1. `capacity.js`: `UTIL_BANDS = Object.freeze({FREE_BELOW:70, NEAR_FROM:101, OVER_ABOVE:110,
   MAX_PCT:150})` — الثابت الواحد للview الجديد والعميل؛ بقية المستهلكين (sector/people/
   attention) **لا يُلمسون** هذه الموجة.
2. `org.js staffingRoster`: SELECT + صف الهدف يكسب `bucket`؛ صف الموظف يكسب
   `capacity_pct/hire_date/end_date/active`؛ خيار `opts.department` يضيّق **داخل** النطاق
   المحلول فقط (فاشل-مغلقاً). summary بايت-ثابت (اختبار `staffing-summary` مثبِّت).
3. جديد `org/staffing-gaps.js` (نقي بلا DB): `activeInMonth` (نشط ∧ hire≤آخر الشهر ∧
   end≥أوله، مقارنة ISO) · `pastMonthsOf` (ماضية 1..12؛ حالية 1..الشهر السابق — **الحالي
   مستثنى**؛ مستقبلية []) · `gapsFor(roster, year)` → {byEmp, gapMonths, activeMonths,
   employeesWithGaps}. «صفر صريح» لا يوجد في التخزين (0 يمسح المفتاح) فكل صفر ماضٍ لنشطٍ
   فجوة.
4. `projects.js`: `setAllocationMonths(ctx, id, monthsMap)` — تفويض ورسائل الخلية نفسها،
   تحقق 1..12 + قصّ 0..150 + 0 يمسح، تحديث واحد + **audit واحد** بتفصيل الأشهر؛ dispatch
   أول في `setAllocation` (قبل فرع `{month}` — مفاتيح منفصلة، فرعا الخلية والمدى بلا مساس).
5. `projects.js`: `bulkStaffing(ctx, {year, ops})` — ثلاث عمليات
   (`assign` project|bucket / `set` months / `remove`)، سقف 100، `tx()` واحد **الكل أو لا
   شيء** (انحراف مقصود عن bulkUpdateTasks — decision-log ق٤)، الفشل يسمّي بنده، كل عملية
   عبر دالتها القائمة ⇒ التفويض والتدقيق القائمان (rollback يسحب التدقيق معه).
6. `api.routes.js`: سطر `POST /api/staffing/bulk`.

## ٥) العقود المحفوظة حرفياً (تكسرها = كسر اختبارات قائمة)

- مرساة الجولة **`#staff-q`** — يرندر لكل الأدوار (فحص الأنكر الميت `guide-page.test.js`).
- شكل شرائح القطاع `/app/staffing?sector=…` + استثناء وحدات المساندة + قرب اسم الموظف من
  وحدته ≤300 حرف (`support-unit-surfaces:178-187`).
- مفاتيح `__SANAD`: `workBuckets:` بأسمائها («تطوير منتجات»/«إدارة مشاريع») و`staffYear:`
  (`internal-work-staffing:123-129`).
- «لا أعضاء ضمن نطاقك» (`department-scope-people`).
- عقد `PATCH {month,pct}` (`staffing-edit`) ورسالة منع التكرار /مسبق|مُسكَّن/ (governance).
- استيراد `staffingPage` من `views/people.js` (أربعة اختبارات) ⇒ إعادة تصدير من هناك،
  **ولا** يضاف `views/staffing.js` إلى barrel `pages.js` (ازدواج `export *` يسقط الاسم).
- `app.js` مجمَّد — الصفحة تتوقف عن استدعاء `empAssign` بدل تعديله.

## ٦) الانحرافات المعلنة عن صور الهدف (قاعدة عدم الاختراع)

2. لا ساعات ولا «توصيات ذكية» ولا «المهارات» — محظورة نصاً في الحزمة (طور لاحق).

4. فجوات الماضي تُنسب للقطاع/الإدارة الحالية — لا تأريخ هيكلي (قرار ترحيلة 007).
5. App Shell كما هو.
