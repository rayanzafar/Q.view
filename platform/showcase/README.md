# showcase — صفحة العرض التعريفي لمنصة سند

صفحة واحدة، عربية بالكامل (RTL)، داكنة، تُعرض على شاشة كبيرة (1920×1080) بتمرير المُقدِّم.
المخرَج النهائي **ملف HTML واحد** يحمل كل شيء بداخله (الخطوط والشعارات واللقطات والأنماط والسكربت) ويعمل بلا اتصال.

## المصادر (`src/`)

| الملف | ما فيه |
|---|---|
| `src/index.html` | ثلاثة عشر مشهداً + كل النص العربي + مواضع اللقطات ونقاط تركيب القطع |
| `src/styles.css` | نظام التصميم الداكن: الرموز المشتركة، إطارات الأجهزة، الكشف والعمق، المسار |
| `src/app.js` | محرّك الحركة (بلا اعتمادات): الكشف، العمق، العدّادات، تتبّع المشهد، مفاتيح المُقدِّم |
| `src/fonts/` | نسخ تطويرية من IBM Plex Sans Arabic (Regular/Medium/Bold) — للعرض المحلي فقط |
| `src/brand/` | نسخ تطويرية من شعارات EVC — للعرض المحلي فقط |

> نسخ `fonts/` و`brand/` هنا للعرض المحلي قبل البناء؛ المصدر الحقيقي يبقى `src/web/public/`.

## الخط الزمني: التقاط ← بناء ← تحقق

```bash
# 1) نسخة محلية مؤقتة ببيانات العرض (خيالية بالكامل)
node scripts/showcase-up.mjs --port 4700

# 2) التقاط اللقطات (49 لقطة) → shots/*.webp + shots/manifest.json
node scripts/showcase-capture.mjs --base http://127.0.0.1:4700

# 3) البناء: كل شيء داخل ملف واحد → dist/sanad-showcase.html
node scripts/showcase-build.mjs
node scripts/showcase-build.mjs --placeholders   # قبل توفر اللقطات: تدرجات معنونة

# 4) التحقق على المخرَج
node scripts/showcase-verify.mjs
```

التحقق يكتب لقطةً لكل مشهد في `verify/scene-NN-*.png` عند 1920×1080، ويسقط التشغيل عند أي فحصٍ ساقط.

## قواعد لا تُخالَف في الأشهر

أي شريطٍ زمنيٍّ (شريط المخرجات `.dv`، منحنى المتوقع `.fc`) يقرأ من يناير يساراً إلى ديسمبر يميناً (`dir="ltr"`) — كما `cap-strip` في `src/web/views/sector.js`. وما كان تصنيفاً لا زمناً (المصفوفة الحرارية `.hm-grid`، شريط التبويبات) يبقى من اليمين إلى اليسار.

وألفاظُ الحالات والعتبات تُنسخ من المنصة لا تُخترع: حالات المخرَج من `DELIVERABLE_STATUS_AR`، وعتبات الطاقة الثلاث (سعة متاحة / ضمن الطاقة / تجاوز الطاقة) من `src/core/i18n/thresholds.js`.

## عقد الأصول مع سكربت البناء

| في المصدر | ما يفعله البناء |
|---|---|
| `<link rel="stylesheet" href="styles.css" data-inline="css">` | يستبدله بـ `<style>` مضمَّن |
| `<script src="app.js" data-inline="js" defer></script>` | يستبدله بـ `<script>` مضمَّن (مع تهريب `</script>`) |
| `url("fonts/IBMPlexSansArabic-*.woff2")` داخل `@font-face` | يحوّلها إلى `data:` (Regular 400، Medium 500‑700، Bold 800‑900) |
| `<img src="brand/*.svg" data-inline-svg alt="…">` | يستبدل الوسم بمحتوى الـ SVG الخام (ليتحكم فيه CSS) |
| `<img data-shot="…" alt="…" decoding="async">` بلا `src` | يضع `src` و`width` و`height` من `shots/manifest.json` |

لا يوجد في الصفحة أي رابط خارجي — لا شبكة توصيل محتوى ولا خطوط بعيدة. المسموح وحده `mailto:`/`tel:` إن أضيفا لاحقاً.

## معاينة محلية قبل توفر اللقطات

أي خادم ملفات ثابت فوق `src/` يكفي (اللقطات تظهر فارغة). الطريقة المعتمدة هي
`node scripts/showcase-build.mjs --placeholders` ثم فتح `dist/sanad-showcase.html`.

## ما يجب أن يبقى صحيحاً

- كل مشهد يتّسع في `100svh` عند 1920×1080 وعند 1440×900 — لا تمرير أفقي إطلاقاً.
- كل `<img>` له نصٌّ بديل عربي وصفي.
- كل رقم داخل `.tnum` وبأرقام لاتينية (`Intl.NumberFormat('en-US')`).
- «تقليل الحركة» يصل بكل شيء إلى حالته النهائية فوراً، ولا يشغّل أي حلقة رسم.
- لا مصطلح تقني في أي نص يقرأه المستخدم (`BANNED` و`RAW_ENUM` في `scripts/check-glossary.mjs`).
