# ADR-0001 — المعمارية الأساسية لإعادة بناء «سند»

- **الحالة:** معتمد
- **التاريخ:** 2026-07-13
- **السياق:** إعادة بناء منصة «سند» من تطبيق React أحادي الملف (JSX يُصرّف في المتصفح) + خادم يخزّن وثيقة JSON واحدة (`/api/state`)، إلى منصة تشغيل مؤسسية آمنة قابلة للتوسع. القيود الأساسية مستخرجة من تقرير التحليل `docs/02-analysis-report.md`: (R1) تفويض من جهة المتصفح، (R4) غياب كيانات مالية/تعاقدية، (R6) نموذج وثيقة واحدة يحدّ التزامن.

## القرار
1. **نمط معماري: Modular Monolith.** حجم المؤسسة (عشرات المستخدمين، قطاعات محدودة) لا يبرّر Microservices. نستخدم monolith معياري بحدود نطاق واضحة (`src/modules/*`) وطبقة نواة مشتركة (`src/core/*`)، قابل للفصل مستقبلًا عند الحاجة.
2. **التنفيذ: Node.js 22 + Express 5.** ESM، بلا خطوة بناء للواجهة (SSR)، لتقليل الاحتكاك التشغيلي.
3. **قاعدة البيانات: علائقية.** التطوير على SQLite المدمج (`node:sqlite`) لعدم الحاجة لأي تبعية أصلية؛ الإنتاج على PostgreSQL. العزل عبر **طبقة مستودعات (Repository layer)** تُخفي فروق اللهجة (SQL dialect) خلف واجهة واحدة.
4. **الأمان أولًا: التفويض على الخادم حصريًا.** لا قرار صلاحية في المتصفح. كل مسار محمي بوسيط RBAC (resource × action × scope) وحجب حقول حساسة على مستوى الخادم.
5. **التدقيق:** سجل تدقيق غير قابل للتعديل لكل عملية كتابة وقرار اعتماد.
6. **الوظائف الخلفية والبريد:** طابور داخلي (in-process job queue) للتطوير، بواجهة قابلة للاستبدال بـ (Redis/BullMQ) إنتاجًا. البريد عبر Transport قابل للتوصيل (dev = معاينة/ملف، prod = SMTP).
7. **بلا اعتماد شبكي وقت التشغيل:** كل الأصول محلية (`/vendor`)، ولا يتطلب التشغيل الأساسي أي طرف خارجي (الذكاء الاصطناعي والبريد الحقيقي إضافات تُفعَّل بمفاتيح وقت النشر).

## البدائل المرفوضة
- **الإبقاء على نموذج الوثيقة الواحدة:** مرفوض — لا يدعم التزامن ولا التفويض الدقيق ولا التقارير القابلة للتوسع.
- **Microservices:** مرفوض حاليًا — تعقيد تشغيلي بلا مبرر حجم.
- **TypeScript + Vite SPA:** مؤجل — يضيف خطوة بناء ومخاطر بيئة؛ نبدأ بـ SSR + JS حديث موثّق بـ JSDoc، ويمكن ترقية الواجهة لاحقًا دون تغيير الخادم.

## التبعات
- طبقة المستودعات تكلفة إضافية بسيطة مقابل قابلية النقل لـ Postgres.
- SQLite المدمج تجريبي (experimental) في Node 22 — مقبول للتطوير؛ الإنتاج Postgres.
- SSR يبسّط الأمان والطباعة (تقارير/PDF) على حساب بعض التفاعلية الغنية (Gantt) التي تُبنى كجُزُر JS لاحقًا.
