## How to use this file

- **New defect found** → add a row immediately (next free `KI-###`, never reuse an ID), with severity, status, `file:line` evidence, and a named next action + owner.
- **Fixing a row** → remove it **in the same commit** as the fix, add a regression test, and record it in `docs/CHANGELOG.md`. A fix without test + changelog entry is not done.
- **Status changes** (e.g. owner decides D15) → move the row to the right group, keep the ID.
- Verify evidence lines still match before acting on a row — line numbers drift; the claim, not the line number, is the anchor.
