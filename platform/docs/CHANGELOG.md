# سجل التغييرات — سند

## v1.0.0-slice.1 — 2026-07-13 — إعادة البناء المؤسسي (شريحة رأسية عاملة)
### أضيف
- **معمارية جديدة:** Modular Monolith (Node 22 + Express) بقاعدة بيانات علائقية (50+ جدول) بدل نموذج الوثيقة الواحدة.
- **أمان مؤسسي:** تفويض على الخادم (RBAC: 16 دورًا × resource×action×scope)، حجب حقول حساسة (رواتب/تكلفة/هوامش/IP)، جلسات آمنة، scrypt، قفل، سجل تدقيق.
- **الوحدات:** CRM/الفرص (+مراحل+تاريخ)، PMO (مشاريع/مهام/Quick-Add)، Timesheets (تحقق+إشغال+اعتماد)، Workflow (اعتمادات متعددة الخطوات بحدود مالية)، المالية (عقود/فواتير/تحصيل schema + اشتقاق ترحيلي)، الإشعارات.
- **التقارير والبريد:** محرك تقارير + قوالب تنفيذية (Outlook/Gmail-safe RTL) + جدولة + طابور + سجل إرسال + معاينة، مع إنفاذ الصلاحيات لكل مستلم وقت البناء والإرسال.
- **الواجهة:** SSR عربي RTL بهوية EVC، ملاحة حسب الدور (مُنقّاة على الخادم)، 12 صفحة.
- **الترحيل:** سكربت ترحيل من لقطة النظام القديم مع تقرير مطابقة؛ اشتقاق العقود/الفواتير.
- **الاختبارات:** مجموعة أمن/صلاحيات/حجب/مال (9/9).
- **التوثيق:** ADRs، مخططات تفصيلية (بيانات/RBAC/API/بريد/KPI/ترحيل)، أدلة نشر/تراجع/أدمن/مستخدم، جاهزية إنتاج، تقرير أمن.

### أُصلح (أثناء البناء)
- **فقد مالي في الترحيل:** كان سطر إيراد بقيمة 30.7M ريال يُسقط لعدم وجود مشروعه؛ صار يُحفظ بلا ربط ويُوسم (لا فقد). الإيراد يطابق المصدر (61,188,430 ريال).
- صلابة الترحيل ضد معرّفات مكرّرة في بيانات المصدر (مشكلة جودة موثّقة سابقًا).
