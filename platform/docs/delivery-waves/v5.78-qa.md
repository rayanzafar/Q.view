# v5.78 — تسليم المشروع والمستهدفات وحفظ البيانات

الحالة: منفذة محليًا، غير منشورة. 2026-09-06. الفرع المصرح:
`claude/evc-platform-analysis-r5nsri`. فريق التنفيذ: تسليم المشروع، المستهدفات السنوية،
المخاطر والاختبارات، حفظ البيانات والتشغيل؛ دمج ومراجعة مركزية. لا ادعاء اكتمال المنصة.

## ما تغيّر ولماذا

- فرصة فائزة → مشروع واحد غير مقيّم، مع استكمال موجّه لستة أقسام محفوظة. القيمة الأولية
  تظهر من الفرصة بمصدرها وصلاحيتها، ولا تصبح عقدًا مؤكدًا بمجرد الفوز. العودة والحفظ لا
  يفقدان البيانات. سنة بدء العقد لم تعد تسمى سنة توقيع أو تؤخذ من بداية المشروع.
- المشروع اليدوي → فرصة مرآة بسنة بيع صريحة، وإلا غير مؤكدة ومستبعدة مؤقتًا. تأكيد السنة
  يصلح المرآة الجديدة غير المؤرخة؛ السنوات والاستبعادات التاريخية المعروفة لا تتغير.
  التراجع عن الفوز المرتبط يرفض الحذف التلقائي ويوجه إلى مراجعة الإلغاء والربط.
- `/app/sector-targets`: اختيار قطاع مسموح وسنة، قيم مبيعات/إيراد، سبب وتاريخ وصاحب
  التعديل والقيمة السابقة. `GET/PUT /api/org/sectors/:id/targets` محروس بالخدمة نفسها.
  صفحات القطاع والهيكل والدليل تقود إليه، والدخول العام بلا معاملات يعرض اختيارًا صالحًا.
- الترحيلة043 تضيف budget.revision وفهرس القطاع/السنة فقط، دون تعيين سنة لقيمة قديمة
  أو دمج تكرار. التعديل القديم يُرفض بدل الكتابة فوق تعديل أحدث. الحقول الشهرية والتكاليف
  محفوظة، والحقول الحساسة لا تصل إلى استجابة المستهدفات العامة.
- القيادة والقطاع والتقارير والبريد والمساعد تقرأ مستهدف سنة المقارنة. الغياب/تعدد السجلات
  لا يعامل صفرًا أو يعتمد أحدها عشوائيًا. تغيير 2026 لا يغير صف 2025.
- معالم بلا موعد صالح لا تعطي تقييمًا أخضر؛ المعالم المتأخرة المعروفة تبقى ذات أولوية.
  عرض أساس الأوزان وتعارض الإكمال والقبول لا يغير نسب المشروع القائمة. غير المقيّم
  يظهر في عداد الصحة وتفصيل المحفظة والقطاع بدل الاختفاء أو اللون الأخضر.
- بدء التشغيل لا يستدعي أي بذور تجريبية أو إصلاحات بيانات تاريخية، حتى مع مفتاح تجريبي
  محفوظ سابقًا. السكربتات الأصلية باقية دون تشغيل. مسار الإصدار يرفض --no-backup
  و--dry-run غير المنفذ قبل أي أمر، ويوقف النشر إذا أخفقت النسخة الاحتياطية.

الإخفاقات الوسيطة عولجت قبل النتيجة النهائية: رابط مستهدف أُدرج خطأ في عقدة الإدارة
وصحح إلى القطاع، وصف/جولة الصفحة الجديدة، فتح الصفحة دون معاملات، وبذور اختبار بمستهدف
بلا سنة. تعديل اختبار أثر الحساب اختار معرّف الحساب بدل أحدث ختم قد يتساوى بالمللي ثانية.
أول مسح مستقل فقد عملية QA بسبب دورة حياة بيئة الأوامر؛ أعيد تشغيل البناء والمسح والتنظيف
داخل عملية واحدة. المسح التالي كشف صفحة المستهدفات بلا معاملات400؛ أصلحت وأعيد التحقق.
لم تُخفَ الإخفاقات بتخطي الاختبارات أو إعادة منطق فقد البيانات.

## التحقق البصري والحدود

المسار المراد تجربته: مركز القطاع → مستهدفات السنة → حفظ التعديل → السجل والمقارنة؛
والفرصة الفائزة → استكمال المشروع → حفظ قسم ثم العودة. متصفح Cloud متاح لكن فتح عنوان
QA المحلي أعاد `net::ERR_BLOCKED_BY_CLIENT` قبل عرض الصفحة، فلم تُجرب النقرات أو تُلتقط
لقطات أو تُفحص المقاسات/الكونسول. لا دليل بصري يدعم اعتماد التصميم حتى الآن؛ SSR وHTTP
يثبتان حدودًا أخرى فقط. لا تحويل عنوان أو تجاوز حاجز المتصفح.

لم يُختبر PostgreSQL أو النشر أو الاستعادة فعليًا. الوصول الخارجي ما زال غير متحقق بعد
عوائق المصادقة الموثقة في v5.76؛ لم تجرِ محاولة نشر أو كتابة بيانات تشغيل في هذه الدفعة.
الترحيلات القديمة المطبقة على البيئة غير معروفة؛ بعضها يحتوي تعديل/حذف بيانات تاريخي.
لذلك يُراجع فرق الترحيلات المطبقة قبل الإصدار، ولا تُعدّل الترحيلات المنشورة لتجاوز العائق.

## تجربة المالك بعد توفير QA قابلة للعرض

1. فرصة تجريبية بقيمة معلومة وسنة2025: حوّلها إلى فائزة، ثم افتح المشروع الواحد.
   ترى قيمة البيع بمصدرها، والعقد غير مؤكد، والصحة غير مقيّمة. أكمل البيانات واحفظ وعد.
2. سجّل مخرجات2026؛ راجع استقلال سنة البيع عن التنفيذ والإيراد. لا نستخدم هذا المثال
   لتغيير مشروع الشركة الفعلي دون عرض أدلته عليك.
3. مستهدف2025 ثم2026؛ غيّر2026 مع السبب وتحقق من سجل التعديلات وثبات2025. افتح نافذتين
   وعدّل الأولى ثم الثانية: التعديل القديم يُرفض ويبقى مدخله مع رسالة إعادة المراجعة.
4. أدوار القائد والمدير والموظف: راجع حدود عرض المستهدفات والمشروع والفرصة والحقول المالية.
5. مشروع بلا تقييم ومعلم بلا موعد: لا أخضر تلقائيًا. افحص سبب نسبة الإنجاز وتحذيرات أساسها.

## المتبقي والتراجع

تسوية السجلات الحقيقية وأسماء الجهات والمخرجات مع مصادرها KI-102…104 لم تنفذ.
KI-109 أساس الإنجاز وحدود الخطر/الجدول، KI-110 توزيع الأشهر وتاريخ التقارير، KI-111
الترحيلات الحية، KI-112 الإلغاء والربط مع حفظ التاريخ. الموصل الخارجي GPT/Claude غير منفذ.
الاستكمال الحالي قائمة إرشاد ببيانات محفوظة، وليس مسار اعتماد جاهزية جديدًا أو حقل نطاق جديدًا.

التراجع يكون بإصدار مضبوط، مع الاحتفاظ بعمود revision والبيانات السنوية المضافة؛ لا حذف
عمود أو صفوف. العودة إلى كود قديم تعيد افتراض المستهدف غير المؤرخ والإقلاع التاريخي، لذلك
ليست rollback آلية آمنة بلا مراجعة الإصدار المختار. النسخة الاحتياطية إلزامية قبل أي نشر.
