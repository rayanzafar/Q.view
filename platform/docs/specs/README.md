# مخططات التصميم (Reference Specs)

هذه مخططات مرجعية أُنتجت عبر مسار تصميم متوازٍ لتوثيق النطاق الكامل. **مصدر الحقيقة للتنفيذ هو الكود** (`migrations/001_init.sql`, `src/`, والـADRs)، وحيثما اختلف مخطط عن الكود يُرجَّح الكود.

| الملف | الحالة |
|-------|--------|
| `01-data-model.md` | مرجعي — نموذج بيانات موسّع |
| `02-rbac.md` | مرجعي — نموذج صلاحيات مؤسسي (16 دورًا، حساسية حقول، سلّم اعتماد) |
| `03-api-contract.md` | مرجعي — عقد API |
| `05-kpi-framework.md` | مرجعي — 25 مؤشرًا قابلًا للتخصيص |
| `06-migration-map.md` | مرجعي — خريطة الترحيل |
| `04-email-templates.md` | **غير مُنتَج** (فشل الوكيل) — قوالب البريد **مُنفَّذة في الكود** بدلًا منه: `src/core/mail/templates.js` |

## فرق مقصود بين المخططات والتنفيذ
- **المال:** المخططات المولّدة استخدمت `*_sar NUMERIC`. **التنفيذ يستخدم `*_halalas INTEGER`** (أعداد صحيحة/هللات) عمدًا لتفادي انحراف الفواصل العائمة في نظام مالي — انظر `docs/adr/ADR-0002`. التنفيذ هو المعتمد.
- مراجعة الاتساق المستقلة (نتيجتها `major-issues`) رصدت هذا الفرق وفروقًا تسموية أخرى بين المخططات؛ عُولجت بجعل الكود+ADR المرجع الموحّد.
