# سنـد (Sanad) — دليل التشغيل والاختبار الذاتي

هذه حزمة **جاهزة للتشغيل** تحتوي على المنصّة كاملةً + بيانات EVC الحقيقية مُرحَّلة مسبقًا
(134 فرصة، عقود، مستخلصات، إيراد 61,188,430 ر.س. عبر السنوات). شغّلها على جهازك وجرّبها
بنفسك بالكامل. **لا علاقة لها بمنصة الإنتاج الحالية os.evcsol.com — منفصلة تمامًا.**

## المتطلّبات
- Node.js نسخة 22 أو أحدث (المنصّة تستخدم SQLite المدمج في Node، بلا أي مكتبات أصلية).
- تأكّد من النسخة: `node --version` (يجب أن تبدأ بـ v22).

## التشغيل (3 خطوات)
```bash
cd platform
npm install          # يثبّت express و cookie-parser فقط (لا تبعيّات ثقيلة)
npm start            # يشغّل الخادم على http://127.0.0.1:4000
```
افتح المتصفح على: **http://127.0.0.1:4000**

> قاعدة البيانات المرفقة `data/sanad.db` محمّلة مسبقًا بالبيانات الحقيقية، فلا تحتاج
> إلى ترحيل أو بذر. إن أردت البدء من الصفر: احذف `data/sanad.db*` ثم شغّل
> `npm run migrate && npm run seed`.

## ماذا تجرّب (اختبار كامل)
1. **لوحة الرئيس التنفيذي** (`demo.ceo` → `/app/ceo`): الملخّص التنفيذي بالسنين،
   Book-to-Bill، نسبة الفوز لكل سنة، الإيراد الربعي، مبدّل السنة أعلى الصفحة.
2. **المالية** (`/app/finance`): AR aging، DSO، الجسر المالي (حجز→إيراد→فوترة→تحصيل)،
   التفصيل **لكل مدير مشروع** و**لكل عقد**. افتح عقدًا → المخرجات والمستخلصات (مستخلص = progress claim).
3. **إصدار مستخلص**: من صفحة العقد، سجّل الدخول كـ`demo.finance`، أصدر مستخلصًا من
   المخرجات المُسلَّمة ثم سجّل تحصيلًا — لاحظ تغيّر الحالة (صادر → مدفوع جزئيًا → مدفوع).
4. **التحكّم بالصلاحيات (RBAC)**: سجّل الدخول كـ`demo.bd` وافتح مشروعًا — التكلفة والهامش
   **محجوبة**. جرّب نفس الصفحة كـ`demo.finance` — تظهر. هذا تفويض من الخادم لا من الواجهة.
5. **المساعد الذكي**: الزر أسفل الشاشة. اكتب «افحص جودة البيانات» أو اطلب نقل فرصة —
   المساعد **يقترح** ولا يكتب إلا بعد تأكيدك (preview → apply) وضمن صلاحيّاتك.
6. **التقارير**: `/app/reports` → معاينة القوالب الستة + جدولة إرسال (يُكتب إلى
   `data/outbox` كمعاينة HTML بلا إرسال شبكي فعلي في وضع التطوير).

## المساعد الذكي مع مفتاح (اختياري)
يعمل المساعد محليًّا **بلا مفتاح** (محرّك heuristic). لترقية الجودة انسخ `.env.example`
إلى `.env` وضع مفتاحك (يُفضَّل `ANTHROPIC_API_KEY`). لا يُرسَل إلى المزوّد إلا سياق **محجوب**.
