# خريطة سند الحية

افتح `index.html`: مستند مستقل يعمل دون اتصال. اختر الطبقة ثم ابحث واضغط العنصر؛ تظهر
مصادره وحالته والعناصر المرتبطة به، ويمكن الانتقال إلى أي جار أو تنزيل القراف كاملًا.
الملف للمراجعة والتطوير، وليس شاشة جديدة في منتج سند.

## ما تغطيه الخريطة

- رحلات العملاء والفرص والمشاريع والمخرجات والإيراد والشخص والمهام والتسكين والاعتمادات
  والتقارير وجودة البيانات والمساعد والفعاليات.
- سنة البيع وفترة الإيراد ومقام نسبة التسكين والفرق بين الخطة وحمل المهام وتغطية التكلفة.
- ملفات التنفيذ والاختبارات وأدوات التشغيل، والوحدات والصفحات الرئيسية وتصريحات المسارات.
- الجداول والحقول والمفاتيح الأجنبية المستخرجة من قاعدة فارغة بعد الترحيلات؛ ليست بيانات الشركة.
- الأدوار ومنحها الافتراضية، وسجل الفجوات القائم، وخط التطوير والنشر وحالة الاتصالات المتحققة.

## كيف تُقرأ الأدلة

| العلاقة | الدليل | الحد |
|---|---|---|
| مفتاح أجنبي | مخطط جديد بعد الترحيلات الحالية | لا يثبت صحة روابط السجلات الحية |
| استيراد صريح | مسار ثابت في المصدر، بما فيه import النصي المؤجل | التعبيرات المركبة لا تحل آليًا؛ الاستيراد لا يثبت استعمال كل دالة |
| إشارة جدولية | اسم جدول صريح في SQL أو مساعد إدخال/تعديل | تحليل نصي؛ قد يشمل تعليقًا أو فرعًا غير منفذ؛ ليس تتبعًا تنفيذيًا |
| تصريح مسار | فعل ومسار نصيان في ملف router | الحارس وبادئة التثبيت في المصدر؛ لا يعد ظهور التصريح نجاحًا للرحلة |
| منح دور | ROLE_GRANTS | لا يشمل المنح الحية والاستثناءات والعضويات ونطاق مستخدم بعينه |
| علاقة أعمال | نموذج محرر في model.json مع مصادر | يفسر المقصد؛ لا يخترع قيدًا في قاعدة البيانات |
| مشكلة | KNOWN-ISSUES | بند مسجل يحتاج مراجعة مصدره؛ ليس نتيجة فحص حي جديد لكل البنود |

الرسم يعرض مجموعة محدودة ليبقى مقروءًا، والقوائم والبيانات تشمل جميع العناصر.
لا تُخلط «علاقة استيراد اختبار» بتغطية سلوك مثبتة؛ دليل نتيجة الاختبار في سجل الدفعة.
والتكامل مع GPT/Claude مُسمّى غير منفذ خارجيًا، والمالية الملغاة لا تظهر كصفحة نشطة.

## التحديث والبوابة

من `platform/` شغّل `npm run graph` بعد تغيير المصدر أو الترحيلات أو الاختبارات أو سجل
المشكلات أو نموذج العلاقات. يبني المخطط في قاعدة مؤقتة ويحذفها، ولا يقرأ `.env` ولا قاعدة تشغيل.
ثم `npm run graph:check` للتحقق من بصمة المصادر؛ CI يفشل عند قدم الخريطة.

- `model.json`: المعنى التجاري والقرارات والربط اليدوي الموثق.
- `graph.json`: الجرد الكامل القابل للاستهلاك آليًا.
- `index.html`: نسخة القراءة المستقلة؛ المصادر تفتح بروابط نسبية عند وجود المستودع بجانبها.
- `viewer.html`: قالب العرض، لا يُفتح بدل النسخة المولدة.
- `scripts/build-system-graph.mjs`: الجرد والتوليد؛ `scripts/lib/graph-schema.mjs`: استخراج المخطط عبر طبقة البيانات القائمة.

الخريطة لا تستخدم خدمة رسم أو نموذجًا خارجيًا، ولا ترسل محتواها خارج الجهاز. ليست بديلاً عن
مراجعة التصميم أو اختبار الرحلة. فحص المتصفح على البيئة الحالية ما زال متعذرًا وفق سجل v5.76.
