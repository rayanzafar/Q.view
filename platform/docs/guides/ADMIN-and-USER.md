# دليل مدير النظام والمستخدم — سند

## مدير النظام (admin)
- **المستخدمون والصلاحيات** (`/app/users`): إنشاء حساب، تعيين دور وقطاع، تفعيل/تعطيل، توليد كلمة مرور مؤقتة. لا يمكنك تعطيل حسابك أو خفض دورك بنفسك (يمنعه الخادم).
- **الأدوار:** 16 دورًا معرّفًا مع منح `role_permission` قابلة للتعديل (النطاق: company/sector/department/project/team/own). الأدوار النظامية لا تُحذف؛ أنشئ أدوارًا مخصّصة عند الحاجة.
- **الهيكل التنظيمي:** أضِف/عدّل قطاعًا/إدارة/وحدة/فريقًا/منصبًا؛ انقل موظفًا؛ اربط موظفًا بعدة مشاريع (membership). كل ذلك بيانات لا كود (بلا Hard-coding).
- **التقارير والبريد** (`/app/reports`): عرّف تقريرًا، أنشئ مجموعة مستلمين، اضبط الجدول (يومي…سنوي)، عايِن، أرسل نسخة اختبار، تابع سجل الإرسال (Outbox) والفشل/النجاح.
- **سجل التدقيق** (`/app/audit`): كل عملية حساسة مسجّلة (من، متى، ماذا).

## المستخدم العام
- **مهامي** (`/app/tasks`): إضافة سريعة (Quick Add) بعنوان وأولوية وتاريخ؛ حدّث الحالة مباشرة.
- **سجل الوقت** (`/app/timesheet`): سجّل ساعاتك يوميًا (قابلة/غير قابلة للفوترة)، تُمنع القيم غير المنطقية وتجاوز 16 ساعة/يوم؛ راجع نسبة إشغالك.
- **الفرص/المشاريع:** حسب دورك ونطاقك؛ الحقول المالية الحساسة تظهر فقط للمصرّح لهم.
- **الاعتمادات** (`/app/approvals`): إن كنت معتمِدًا، تظهر الطلبات بانتظارك مع اعتماد/رفض.

## ملاحظة الخصوصية
الرواتب والتكلفة والهوامش وعناوين IP تُحجب على الخادم حسب الدور — ما لا تراه لا يصل متصفحك أصلًا.
