# تقرير الأمن — سند (آخر إضافة 2026-09-05؛ حالة النشر معلنة لكل دفعة)

تقرير حالة موجز. التفصيل التاريخي الكامل في `docs/SESSION-HANDOFF.md` §3/§8، والقصور المعروف الجاري في `docs/KNOWN-ISSUES.md`.

## 1. الخلاصة
- فجوات النظام القديم (تفويض في المتصفح، تسريب رواتب/تكلفة/IP عبر الـAPI) **مغلقة منذ إعادة البناء**: تفويض على الخادم حصريًا (`can` + `scopeFilter`)، حجب حقول حساسة (`redact`/`canSeeSensitive`)، استعلامات مُعامَلة حصريًا، `audit_log` لكل كتابة — كلها تحت اختبارات دائمة (`tests/security/`).
- **جولة تحصين شاملة أُنجزت 2026-08-05**: خمس دفعات على PR ‏#3 (commits ‏`d0f8b08`، `77e9be7`، `9f31d1b`، `bf5367a`، `a800d86`) **دُمجت في فرع العمل** `claude/evc-platform-analysis-r5nsri` ونُشرت على staging.
- **مراجعة أمنية مستقلة للفرق: نظيفة** (لا ثغرات ولا انحدارات جديدة). الحزمة الكاملة **1447 اختبارًا / 0 إخفاق**، ولكل إصلاح اختبار انحدار.

## 2. ما أُغلق في دفعات 2026-08-05 (PR ‏#3)
| الدفعة | المحتوى |
|--------|---------|
| A — XSS/حقن (`d0f8b08`) | تهريب `title`/`subtitle` عند المصبّ في `src/web/layout.js`؛ تحقق + تهريب لون/معرّف القطاع؛ إصلاح `?sector=` المنعكس و`?year=` NaN؛ عزل iframe معاينة البريد (sandbox) |
| B — تسريب ردود الكتابة والنطاق (`77e9be7`) | حجب الراتب في ردود كتابة الموظف؛ إسقاط `password_hash`/عدّادات القفل من قائمة المستخدمين؛ تحصين تغيير كلمة المرور (تحقق من الحالية + إبطال الجلسات الأخرى)؛ تصحيح نطاق `scopedRevenue` (لا تسريب قطاع كامل لنطاقات أضيق)؛ `trust proxy = 1`؛ تغليف `tx()` للعمليات متعددة الكتابة؛ رفض المبالغ غير الرقمية؛ حرّاس IDOR على `kpis`/`removal-check`/`unmerge`؛ سدّ تعداد الحسابات في الدخول؛ `deleted_at` على قراءات المخاطر |
| C — تصلّب النشر (`9f31d1b`) | فشل الترحيلة يوقف الإقلاع (`scripts/boot.sh`)؛ استبعاد الأسرار من صور النشر (`.dockerignore`/`.railwayignore`)؛ `/ready` لا يسرّب رسالة الخطأ؛ `npm ci` بلا fallback؛ فحص مسبق للتبعيات قبل الاختبارات |
| D — واجهة/صحة (`bf5367a`) | إزالة روابط المالية الميتة (الصفحة معطّلة)؛ إصلاح شارة الإشعارات؛ إخفاء اسم مزوّد الذكاء الاصطناعي؛ عرض تفاصيل التدقيق بالعربية بلا مفاتيح تقنية؛ إصلاح متغيرات CSS ووصولية صفحة الدخول |
| ختامية (`a800d86`) | تهريب آخر مصبّي `sector=` في الروابط — دفاع متعدد الطبقات |

## 3. الضوابط القائمة (بلا تغيير)
scrypt + قفل بعد محاولات فاشلة، دخول برمز بريد أُحادي (OTP: 6 أرقام، 10 دقائق، استهلاك ذرّي، ردّ موحَّد ضد تعداد الحسابات)، جلسات HttpOnly + SameSite=Lax + Secure إنتاجًا، CSRF مزدوج الإرسال لنماذج الويب (`src/core/http/csrf.js`)، ترويسات أمان + مُقيِّدات معدل للدخول/OTP/الـAPI (`src/core/http/security.js`)، تدقيق غير قابل للتعديل لكل كتابة.

## 4. المتبقّي (مقصود وموثَّق — لا يحجب التشغيل)
| البند | الحالة | الموضع |
|-------|--------|--------|
| CSP | **Report-Only** حتى اكتمال الانتقال onclick → `data-action`؛ التحويل إلى enforcing قرار إصدار لاحق. وتوجيها قارئ البطاقات داخل المتصفّح — `'wasm-unsafe-eval'` على `script-src` و`worker-src 'self'` — مكتوبان منذ E2 من «الفعاليات» (ADR-0014) فلا يكسرهما التحويل؛ ولا `blob:` في أي توجيه | `src/core/http/security.js:17-18,33` |
| CSRF على طلبات JSON | مؤجَّل — التغطية الحالية لنماذج urlencoded فقط؛ SameSite=Lax هو الدفاع المتبقي | `src/core/http/csrf.js` |
| `must_change_pw` | مخزَّن ويُعاد في ردّ الدخول لكن **لا وسيط يفرضه** | `src/core/auth/service.js` |
| `trust proxy` | مضبوط على `1` (قفزة وكيل واحدة — يطابق Railway؛ يُراجع عند تغيير البنية) | `src/server.js:36` |
| مُقيِّد المعدل | في الذاكرة لكل نسخة تشغيل — يضعف عند أكثر من replica واحدة | `src/core/http/security.js` |

بنود ما قبل الإطلاق الأقدم (اختبار اختراق مستقل، تدوير الأسرار عبر خزنة، سياسة كلمات مرور/MFA) ما تزال قائمة كمتطلبات إطلاق إنتاجي — انظر `docs/PRODUCTION-READINESS.md`.
